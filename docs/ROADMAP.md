# Дорожная карта UMBRA

[← Вернуться на главную](../README.md)

Это **ориентировочный план**, а не расписание релизов. Номер версии не гарантирует, что все перечисленные задачи будут завершены к конкретной дате.

## Сейчас

**Alpha 0.76.0** — текущая исходная версия для проверки полной прогрессии; игровая стабильность не подтверждена.

Текущая база: 3 биома, 4 основных босса, 3 мини-босса, событие «Ночное вторжение», оружие, броня, аксессуары, эффекты, RU/EN-переводы. Автоматическая компиляция налажена; игровая стабильность ещё не подтверждена.

## Куда движемся

| Этап | Главная цель | Условие завершения |
|---|---|---|
| **0.68–0.69** | Полировка биомов, событий и генерации | Исходники объединены; игровые тесты ожидаются |
| **0.70 Alpha** | Сохранение событий, исправления прогрессии, подготовка к тестам | Игровое прохождение ещё не подтверждено |
| **0.71–0.79** | Расширение существующих игровых веток | Контент связан с прогрессией и сбалансирован |
| **0.80** | Крупное контентное обновление | Новые механики проходят игровые проверки |
| **0.81–0.89** | Развитие поздней игры | Отлажены ключевые бои и предметы |
| **0.90 Beta** | Завершение основного объёма контента | Полное тестовое прохождение возможно |
| **0.91–0.99** | Баланс, производительность, стабильность | Устранены критические и блокирующие ошибки |
| **1.0** | Публичный стабильный релиз | Игра, генерация и мультиплеер протестированы |

## Что блокирует релиз 1.0

- [ ] Проверить генерацию всех биомов на маленьких, средних и больших мирах.
- [ ] Пройти все существующие бои без пропуска этапов прогрессии.
- [ ] Проверить сохранение и загрузку прогресса в одиночной игре и мультиплеере.
- [ ] Провести сетевые тесты событий, призыва боссов и инвентаря.
- [ ] Проверить эффекты, кадровую частоту и отображение брони в игре.
- [ ] Настроить награды, рецепты, баланс сложности и локализации.
- [ ] Подготовить версию для публичного распространения с документацией.

**Важно:** локальные версии исходников могут опережать `main`. Официальное состояние публичного репозитория определяется только кодом и `build.txt` в его основной ветке.
