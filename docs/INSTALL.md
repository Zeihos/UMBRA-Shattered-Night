# Установка UMBRA

[← Вернуться на главную](../README.md)

> **Статус:** Alpha 0.75.0 в ветке `main`. Это экспериментальная сборка; игровой процесс, мирогенерация и мультиплеер пока не прошли полный цикл тестов.

## Что потребуется

- Terraria и установленный **tModLoader**, совместимый со сборкой.
- Для сборки из исходников — инструменты разработки модов tModLoader.
- Рекомендуется отдельный тестовый мир и резервные копии персонажей/миров.

В GitHub Actions мод компилируется на версии **tModLoader v2026.09.3.1**. Другая версия может оказаться несовместимой.

## Способ 1. Готовый мод из GitHub Actions

1. Открой [страницу сборок](https://github.com/Zeihos/UMBRA-Shattered-Night/actions/workflows/tmodloader-build.yml).
2. Выбери **успешный запуск** для ветки `main`.
3. В разделе **Artifacts** скачай `UMBRA-built-tmod` (может понадобиться авторизация GitHub).
4. Распакуй архив и найди `UmbraShatteredNight.tmod`.
5. Помести файл в каталог модов tModLoader (`Mods` внутри пользовательского каталога tModLoader).
6. Запусти tModLoader, включи UMBRA в списке модов и перезагрузи моды.

Артефакты GitHub Actions доступны ограниченное время — если нужного архива нет, используй сборку из исходников.

## Способ 2. Сборка исходников

1. Получи исходники репозитория: **Code → Download ZIP** или `git clone`.
2. Помести содержимое проекта в `ModSources/UmbraShatteredNight`. Название этой папки важно: оно должно соответствовать внутреннему идентификатору мода.
3. В tModLoader открой **Workshop → Develop Mods**.
4. Выполни **Build + Reload** для `UmbraShatteredNight`.

Указанные имена разделов могут отличаться в переводах интерфейса. Подробности о проверках исходников — в [руководстве разработчика](DEVELOPMENT.md).

## Если возникла ошибка

Сохрани `client.log` (или соответствующий лог tModLoader), укажи версии Terraria/tModLoader/UMBRA и опиши шаги воспроизведения. Создай [сообщение об ошибке](https://github.com/Zeihos/UMBRA-Shattered-Night/issues/new/choose).

**Не публикуй** в логах личные пути, токены и другие приватные данные.
