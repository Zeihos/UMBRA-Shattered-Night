# UMBRA: Shattered Night

Мод для **Terraria / tModLoader** с собственной прогрессией, исследованием подземных биомов и боссами.

**Текущие исходники в `main`: Alpha 0.67.0.** Проверена автоматическая компиляция; полноценное прохождение, генерация мира и мультиплеер ещё требуют тестирования. Это не стабильный релиз.

## Содержимое

- **Три биома:** Расколотая бездна, Астральный разлом и Пепельная пустошь.
- **Четыре основных босса**, три мини-босса и событие «Ночное вторжение».
- Оружие, броня, аксессуары, материалы, предметы призыва.
- Генерация руд, святилищ, прогрессия мира и эффекты сражений.
- Русская и английская локализация.

## Сборка

1. Установи Terraria и совместимый tModLoader. В GitHub Actions используется зафиксированная версия **`v2026.09.3.1`**.
2. Клонируй проект. Для локальной сборки помести исходники в каталог `ModSources/UmbraShatteredNight` — **имя папки должно совпадать с идентификатором мода**.
3. В tModLoader открой **Workshop → Develop Mods → Build + Reload**.
4. При успешной автоматической сборке готовый файл `.tmod` сохраняется как артефакт **`UMBRA-built-tmod`** соответствующего запуска GitHub Actions.

## Проверки

```bash
python scripts/validate_source.py
python scripts/validate_visual_animation.py
python scripts/validate_combat_visuals.py
python scripts/validate_biome_atmosphere.py
```

- **UMBRA source integrity** проверяет исходники, изображения и переводы при push и pull request.
- **UMBRA tModLoader build** компилирует проект при изменении игрового кода, ресурсов и скриптов проверок.
- `scripts/visual_polish.py` — **ручной инструмент**. Графика не должна автоматически перезаписываться CI.
- Бинарные `.tmod`, `bin/`, `obj/` и временные файлы не сохраняются в Git.

**Важно:** успешная компиляция не заменяет проверки непосредственно в Terraria. Для релиза необходимы тесты боссов, генерации миров, сохранений и мультиплеера.
